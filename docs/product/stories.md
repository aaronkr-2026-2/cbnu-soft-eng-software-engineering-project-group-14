# User Stories (8–12)

1. As an HR Admin, I want to log in securely with my email and password so that I can access management tools.
2. As an Employee, I want to log in using my joining date as a temporary initial password so that I can access my account on day one without IT assistance.
3. As an Admin, I want new employee accounts to default to the "employee" role so that unauthorized users cannot access admin privileges.
4. As an Admin, I want the system to read user roles dynamically from MongoDB so that permissions are accurately enforced.
5. As an Employee, I want to view my profile details upon successful login so that I can verify my department and base salary.
6. As a Developer, I want passwords to be hashed using SHA-256 so that user credentials remain secure in the database.
7. As an HR Admin, I want to add new employee documents to MongoDB with fields like email, department, and joining date.
8. As a User, I want to see clear error messages on the login screen if my credentials are invalid so that I know why access failed.
9. As an Employee, I want my session routed automatically to an employee-specific dashboard layout.
10. As an Admin, I want my session routed automatically to a management dashboard layout.
